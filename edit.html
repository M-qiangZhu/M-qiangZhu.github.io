基本信息

使用方式

  1. 连接 GitHub，编辑资料，使用“预览主页”或“预览简历”检查。
  2. 点击“保存并发布”。资料会直接提交到主页仓库，自动触发 Pages 更新。
  3. 提交后等待页面显示“已上线”。主页与简历同步更新，浏览器中尚未发布的修改仍会保留。
备用：手动发布与本地文件
GitHub 手动上传

下载的 content.js 可手动上传到仓库 main 分支。本地文件夹写回需浏览器支持；写回本身不会更新公开网站。
