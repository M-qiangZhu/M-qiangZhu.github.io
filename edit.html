如何更新公开网站

  1. 填写资料，使用“预览主页”或“预览简历”检查。
  2. 点击“下载发布文件”，获得 content.js。
  3. 打开 GitHub 上传页面，上传该文件并提交。部署完成后公开网站会更新。

“写回本地文件夹”适用于已下载或克隆的网站目录。若浏览器不支持，请使用下载文件。仅当你提交到 GitHub 后，公开页面才会改变。
