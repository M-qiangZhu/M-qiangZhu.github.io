# 紧凑主页与双语简历

用户已授权：简化当前主页、收紧行距，增加双语简历导出、自动倒序、共同第一作者处理和表单编辑器，完成后发布到现有 GitHub Pages。

保留无依赖静态站。主页采用单栏、窄宽度、普通标题、紧凑列表，去掉装饰图和营销文案；行高约 1.55，正文 14–15px，段落与章节间距缩小。语言与浅深主题延续。变更在当前仓库分支完成。

资料集中保存；所有视图共用日期排序和作者贡献逻辑。项目按结束时间倒序、再按开始时间倒序；持续中排最前，无日期排最后，同日期保持原顺序。论文按正式出版日期排序，在线日期单独记录。日期允许年份、年月、年月日，不补造缺失月份。共同第一作者与通讯作者使用独立字段，作者列表顺序不变，不从星号或第二作者位置猜测贡献。

独立 cv.html 提供中英切换、章节选择、项目选择和浏览器打印为 PDF。简历打印白底黑字 A4，隐藏所有控件、完整展开选定内容；支持精简的精选项目与完整经历。主页与简历使用相同数据，预览模式可读取编辑器草稿。

edit.html 使用中文表单维护基本信息、工作经历、技能、项目、论文、专利和认证；支持双语字段、增删、原文作者列表、贡献字段、日期字段、精选项目勾选。草稿自动保存；支持 JSON 备份导入导出与 content.js 下载、可用时写回本地目录。导入只解析严格 JSON 或固定导出封装，绝不执行导入脚本；验证结构和危险 URL。预览使用单独 query 参数，正常主页不读取草稿，避免用户把个人草稿误认为已发布。提供明确 GitHub 上传入口，不保存访问令牌或伪装自动远端发布。

比较：迁移学术模板会改变当前工程展示定位；引入后端会增加账户、部署和维护成本；因此在现有静态站补完整工作流。

验证：核心逻辑使用 Node 原生测试；浏览器检查两种语言、主题、手机布局、编辑新增/保存/预览/导入导出、共同一作与日期自动排序、打印预览。独立代码审查后提交、推送现有 main，等待 Pages 成功并核对线上文件。
