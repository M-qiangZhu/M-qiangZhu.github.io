# Mingqiang Zhu · 朱明强

个人网站：[https://M-qiangZhu.github.io/](https://M-qiangZhu.github.io/)

AI application engineering and quantum circuit research. 可切换中英文，支持手机浏览与浅深主题。

## 维护

- `content.js`：双语文案、项目、论文、专利申请和认证。
- `index.html`：页面结构及 CNOT 线路示意。
- `styles.css`：响应式布局与主题样式。
- `app.js`：语言、主题、筛选和展开交互。

GitHub Pages 从 `main` 分支根目录发布。更新文件并推送后会自动部署，无需额外安装依赖。

本地预览：`python3 -m http.server 4173`。
